# 定位点チャレンジ

そろばん3級の「定位法（なんけたから おくか）」を練習するWebアプリです。
けたを選ぶと、そろばんが実際にその棒から問題を置いて計算し、こたえの一の位が定位点に乗るかを見せます。

- 公開ページ: https://sho1murakami.github.io/soroban-teiiten/
- モード: ①けたを かぞえる ②ステップで とく ③チャレンジ（10問）
- 問題: 教室プリント（かけ算・わり算 各20問）とランダム問題

## iPad で使うとき

Safari でページを開き、共有ボタン →「ホーム画面に追加」を選ぶと、アプリのように全画面で使えます。
きろくは その端末のブラウザの中だけに保存されます。

## 定位法の前提

- けた: 整数部分のけた数が＋、0.〇 は 0、0.0〇 は −1
- かけ算: 被乗数のけた ＋ 乗数のけた の棒に、最初の九九の答え（2けた）の十の位を置く
- わり算: 被除数のけた − 除数のけた − 1 の棒から被除数を置く（商は 割れる→2つ左、割れない→1つ左）

ビルド不要の静的サイトです（`index.html` 1ファイル + アイコン）。
